# pingdoiboutiquehotel.com

Static version of the Pingdoi Hualin Boutique Hotel website (moved off WordPress, October 2026).
Hosted on GitHub Pages from the `main` branch, root folder.

## Structure
- `index.html`, `about-us/`, `accommodations/`, `contact/`, `accommodation/<room>/` – English pages
- `th/…` – Thai pages (same URLs with `/th/` in front)
- `wp-content/`, `wp-includes/` – the original theme's CSS, JS, fonts and images (kept so the site looks exactly like before)
- `assets/th.css` – small typography fix for Thai text
- `sitemap.xml`, `robots.txt`, `404.html`, `CNAME`

## Editing
Each page is a plain HTML file. To change text, edit the matching `index.html`
(remember the Thai copy under `th/`). Bookings go through Facebook Messenger:
https://m.me/PingdoiHualinBoutiqueHotel
